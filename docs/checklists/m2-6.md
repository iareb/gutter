# M2.6 checklist — Navigation by hand

Run on the built app before closing M2.6, on each platform. Mark each cell **ok**, **—** (not applicable or no hardware) or the number of the issue opened for it. A failure becomes an issue with the bug report form and, when it is a gesture, a recording added to `tests/recordings/` with a test that replays it.

**Setup.** Generate the volumes with `pnpm corpus`. Desktop: build with `pnpm tauri build --no-bundle` and start `src-tauri/target/release/gutter` (`gutter.exe` on Windows). Android: build and install the debug APK, `pnpm tauri android build --debug --apk --target aarch64` then `adb install -r src-tauri/gen/android/app/build/outputs/apk/universal/debug/app-universal-debug.apk`, and copy `basic.cbz` and `large-solid.cbr` to `Download` with `adb push`.

**Devices.** Windows: mouse and keyboard. Linux: the laptop, with its trackpad. Android: touch only. Items 1 to 8 need a wheel or a keyboard: on the phone they are —.

**The phone** (Motorola edge 60): the new debug APK was installed over the old one, `basic.cbz` and `large-solid.cbr` were opened through the system picker, and the slider was dragged with a real finger (`adb shell input swipe` along the slider). Results: the slider is 386 px wide (CSS pixels) and sits on a row of its own under "Open comic… · Comic · 1 / 20", which makes the bar 98 px high; with the finger down, halfway, the bar said 7 / 20 and no page had been asked for; after letting go page 12 showed in 0.8 s and the slider agreed; a tap on the side turned the page and the slider followed; dragging from one end to the other of `large-solid.cbr` loaded only page 40, shown 2.5 s after the finger left, with "Loading page 40…" in the bar meanwhile.

"Automated" means the action was sent by a script and the result read from the page, as in the earlier checklists: on Windows with real wheel, key and mouse events through the webview's DevTools protocol (the release build); "WSL" is WebKitGTK in WSL with DOM events. Item 1 on Windows and on Linux also includes a trackpad-like flick of small wheel steps, sent as wheel events. The M2 checklist was run again on Windows (all cells) with items 18 and 19 changed to the new rule.

Known limits, not failures: the slider shows no previews of the pages (they come with the thumbnails of M4); on a phone the bar is taller with the slider on a row of its own; Home and End still change the page of a zoomed one; a touch swipe from the edge of a zoomed page still turns it (that is how a page is changed by touch).
